Definición

¿Qué es IBM Bob?

Bob es un asistente de IA integrado en tu editor de código (VS Code u otro IDE compatible). No es solo un autocompletador — es un agente que entiende tu proyecto completo, razona sobre él y actúa tomando decisiones para ayudarte a avanzar más rápido.

"IBM Bob es un socio de IA para el ciclo de vida del desarrollo de software (SDLC) que potencia tus flujos de trabajo existentes y te ayuda a entender, planear, mejorar y trabajar con confianza en proyectos reales."

— Documentación oficial de IBM Bob

Modos de Trabajo

Tres Modos para cada situación

Bob adapta su comportamiento según el modo que elijas. Selecciona el modo correcto para obtener los mejores resultados.

🤖 Modo Agent

Escribir & Modificar

Para implementar features, corregir bugs y hacer cambios en tu código.

  • Crea y edita archivos
  • Ejecuta comandos
  • Implementa funcionalidades completas
  • Modo por defecto para desarrollo
📋 Modo Plan

Planear & Diseñar

Para arquitectura y diseño antes de escribir una sola línea de código.

  • Crea especificaciones técnicas
  • Diseña arquitecturas
  • Estrategias de implementación
  • Ideal para features complejas
💬 Modo Ask

Preguntar & Explorar

Para entender código y obtener explicaciones sin modificar nada.

  • Responde preguntas del código
  • Solo lectura — no modifica
  • Explica cómo funciona algo
  • Ideal para onboarding

💡 Estrategia recomendada

Empieza en Plan para diseñar la solución → pasa a Agent para implementarla → usa Ask cuando necesites entender algo sin hacer cambios. Bob también puede cambiar de modo solo cuando el trabajo así lo requiera.

Guía de Inicio

¿Cómo empiezo a usar Bob?

Cuatro pasos sencillos para comenzar desde cero.

1

Solicita Acceso

Visita w3.ibm.com/w3publisher/bob y completa el formulario de acceso. Tu acceso debe ser aprobado — recibirás un correo de confirmación.

2

Instala la Extensión en tu IDE

Abre VS Code, ve al Marketplace de extensiones y busca IBM Bob. Instala y reinicia tu editor. El panel de Bob aparecerá en la barra lateral.

3

Abre tu Proyecto e Inicializa

Abre la carpeta de tu proyecto en VS Code. En el chat de Bob, escribe /init para que Bob analice el contexto de tu workspace y cree la configuración inicial.

4

¡Escríbele en Lenguaje Natural!

Simplemente escribe lo que necesitas: "Crea una función que calcule el promedio de una lista" o "Explícame qué hace el archivo app.js". No hay comandos que memorizar.

📌 Slash Commands útiles:   /init — Inicializa el proyecto   /review — Revisa el código antes de hacer commit   / — Muestra todos los comandos disponibles

Ejemplo en Vivo

Bob en acción — Caso real

Mira cómo un desarrollador interactúa con Bob para crear una función, entender código y detectar un bug — todo en lenguaje natural.

IBM Bob — mi-proyecto/
AGENT
YO
Crea una función en Python que lea un archivo CSV y retorne el promedio de una columna llamada "precio". Si el archivo no existe, que lance un error claro.
BOB
Entendido. Voy a crear la función en Python con manejo de errores.

📖 leyendo estructura del proyecto... ✏️ escribiendo utils/csv_reader.py

Creé el archivo utils/csv_reader.py:

def get_average_price(filepath: str) → float:
   La función valida que el archivo exista, lee el CSV con pandas, verifica que la columna "precio" exista y retorna el promedio. Lanza FileNotFoundError o KeyError con mensajes descriptivos.
YO
Bien. Ahora explícame qué hace el archivo main.py sin modificar nada.
BOB
🔀 cambiando a modo Ask 📖 leyendo main.py

main.py hace tres cosas:
1. Carga la configuración desde config.yaml
2. Llama a tu función get_average_price() con la ruta del CSV configurada
3. Imprime el resultado formateado con 2 decimales.

El flujo principal está protegido con if __name__ == "__main__" para evitar ejecución accidental al importar el módulo.
YO
Al correr los tests me sale: KeyError: 'Precio'. ¿Por qué?
BOB
📖 leyendo utils/csv_reader.py 📖 leyendo tests/test_csv.py

Encontré el problema. Tu archivo CSV de test tiene la columna como "Precio" (mayúscula) pero la función busca "precio" (minúscula). Solución: normalizar el nombre de columna al leer.

¿Quieres que haga el fix agregando .str.lower() a los nombres de columnas antes de buscar? Esto hará la función insensible a mayúsculas.
YO
Sí, aplica el fix.
BOB
✏️ editando utils/csv_reader.py (línea 8)

Listo. Cambié la línea de búsqueda para normalizar las columnas a minúsculas. Los tests deberían pasar ahora. ¿Quieres que corra pytest para confirmarlo?
